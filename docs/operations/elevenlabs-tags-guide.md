## 1. Tags Básicas (Essenciais)

| Tag            | Efeito                              | Quando usar                          | Intensidade |
| -------------- | ----------------------------------- | ------------------------------------ | ----------- |
| `[narrating]`  | Tom neutro, informativo, documental | Abertura, contexto, transições       | ⭐⭐        |
| `[smiling]`    | Tom levemente sorridente, acolhedor | Boas-vindas, convites, notícias boas | ⭐⭐        |
| `[excited]`    | Voz energética, entusiasmada        | Chamadas, ganchos, anúncios          | ⭐⭐⭐⭐    |
| `[whispering]` | Sussurro íntimo, confidencial       | Suspense, segredos, momentos íntimos | ⭐⭐⭐      |
| `[sarcastic]`  | Tom irônico, seco, cômico           | Piadas, críticas leves, reversos     | ⭐⭐⭐      |
| `[laughs]`     | Risada natural, espontânea          | Final de piada, momentos leves       | ⭐⭐⭐      |

## 5. Tags de Controle de Tempo

> ⚠️ **Atenção:** O ElevenLabs v3 NÃO suporta SSML nativamente via API. Use estas tags como texto dentro do contexto.

| Tag / Padrão        | Efeito                      | Quando usar                     |
| ------------------- | --------------------------- | ------------------------------- |
| `...` (reticências) | Pausa natural, suspense     | Antes de revelações, hesitações |
| `,` (vírgula)       | Micro-pausa                 | Respiração natural entre frases |
| `.` (ponto final)   | Pausa média                 | Fim de ideia, transição         |
| `!` (exclamação)    | Ênfase, energia             | Chamadas, surpresas, urgência   |
| `?` (interrogação)  | Tom ascendente, curiosidade | Perguntas, ganchos              |
| `—` (travessão)     | Pausa dramática             | Interrupções, reviravoltas      |
| `[pause]`           | Pausa breve (simulada)      | Momentos de reflexão            |
| `[long pause]`      | Pausa longa                 | Clímax, suspense máximo         |
| `(silence)`         | Sugerir silêncio            | Antes de fatos impactantes      |

## 6. Combinações Recomendadas

### 🎙️ Abertura de Podcast (Upbeat)

```
[excited] Olha só quem chegou! Mais um Muuday na área!
[smiling] Eu sou a Jessica, e hoje a gente vai embarcar numa
história de coragem e reinvenção.
[excited] Bora? Aperta o play e vem com a gente!
```

### 😢 Momento Emocional (Triste)

```
[narrating] Era uma terça-feira como qualquer outra.
[sad] Mas pra Maria, aquele dia mudou tudo.
[whispering] Ela ainda não sabia... que nunca mais veria
aquele apartamento.
[sighs]
[narrating] Essa é a história de quem teve que escolher
entre o sonho e a saudade.
```

### 😂 Piada / Leveza (Cômico)

```
[narrating] O João chegou no aeroporto de Londres
com duas malas e um sonho.
[sarcastic] E também com a crença de que o inglês
que ele aprendeu na escola seria suficiente.
[laughs]
[smiling] Spoiler: não era.
```

### 😱 Suspense / Thriller (Tensão)

```
[whispering] Tem alguém na porta.
[breathing]
[fearful] Ela congelou. O coração batia tão forte
que ela tinha certeza que ele ouvia.
[shocked] E então... a maçaneta girou.
```

### 💪 Motivacional (Empoderamento)

```
[determined] Levanta a mão quem já ouviu que
"brasileiro não dá certo fora do país."
[angry] Pois é. Eu também ouvi.
[triumphant] E hoje eu tô aqui pra provar o contrário.
```

### 💕 Romântico / Íntimo (Conexão)

```
[gentle] Sabe aquele sentimento de que você finalmente
chegou em casa?
[romantic] Foi assim que ela olhou pra ele.
[sighs]
[smiling] Mesmo estando a 10 mil quilômetros do Brasil.
```

## 7. Anti-Padrões (O que evitar)

| ❌ Não fazer                                  | ✅ Fazer em vez disso                      |
| --------------------------------------------- | ------------------------------------------ |
| `[excited]` durante mais de 2 frases seguidas | Alternar com `[smiling]` ou `[narrating]`  |
| `[shouting]` + `[screaming]` no mesmo bloco   | Escolher um e deixar respirar              |
| `[sad]` → `[happy]` sem transição             | Usar `[nostalgic]` ou `[relieved]` no meio |
| Tags no meio da palavra                       | Sempre entre frases ou no início           |
| 5+ tags em 10 segundos                        | Máximo 2-3 tags por segmento               |
| `[laughs]` sem contexto cômico                | Sempre preceder com algo engraçado         |
| `[crying]` sem buildup emocional              | Construir com `[sad]` primeiro             |

---

## 🎯 Regras de Ouro

1. **Uma tag por segmento** — Nunca misture 2 tags na mesma geração
2. **Segmente para variar** — Gere cada bloco emocional separadamente
3. **Corte as tags faladas** — Use silence detection para remover tags que saíram como palavras
4. **Teste antes** — Sempre gere 5s de amostra antes do segmento completo
5. **Transições suaves** — Deixe 0.3-0.5s de silêncio entre segmentos de emoções diferentes
