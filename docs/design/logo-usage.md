# Logo Usage — Muuday

## Logo Concept

The Muuday logo represents:

- **Connection**: Brazilians connected across the globe
- **Movement**: Arrows/paths suggesting migration and journey
- **Warmth**: Brazilian colors and energy
- **Professionalism**: Clean, modern execution

## Logo Variants

### Primary Logo

- Full logo with icon + wordmark
- Use: Headers, presentations, social media profiles

### Icon Only

- Just the icon (no text)
- Use: Favicon, app icon, profile pictures, watermarks

### Wordmark Only

- Just "Muuday" text
- Use: When icon is already present or space is limited

## Clear Space

Minimum clear space around logo: equal to the height of the "B" in "Brasil".

## Minimum Size

| Variant   | Minimum Width |
| --------- | ------------- |
| Primary   | 120px         |
| Icon only | 24px          |
| Wordmark  | 80px          |

## Color Versions

| Background | Logo Version             |
| ---------- | ------------------------ |
| Light      | Dark text + lime accent  |
| Dark       | White text + lime accent |
| Brand lime | Dark text only           |

## Incorrect Usage

Never:

- Stretch or distort the logo
- Change the logo colors outside approved versions
- Add effects (shadows, glows, gradients)
- Place on busy backgrounds without contrast
- Rotate the logo
- Change the font of the wordmark

## Social Media Profile

### Instagram

- Profile picture: Icon only, centered, on brand lime background
- Highlights: Icon + text, consistent style

### Podcast

- Cover art: Icon prominent, title clear, episode number
- Size: 3000x3000px (Apple Podcasts requirement)

## Watermark

For content (images, videos):

- Icon only, bottom-right corner
- 10% opacity on dark content
- 20% opacity on light content
- Minimum size: 40px
