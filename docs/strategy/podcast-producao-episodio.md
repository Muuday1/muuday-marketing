## 2. Busca de Histórias

### 2.1 Onde Buscar

| Plataforma          | Como Buscar                                                             | Dicas                                                            |
| ------------------- | ----------------------------------------------------------------------- | ---------------------------------------------------------------- |
| **Reddit**          | r/brasil, r/foradoarmario, r/brasileirosnoseua, r/brasileirosnoexterior | Filtrar por "top" + "this year". Procurar posts com 500+ upvotes |
| **Instagram**       | Hashtags: #brasileirosnoseua #vidanoseua #brasileironareino #imigração  | Stories de contas de imigração. DMs podem render histórias       |
| **Facebook**        | Grupos: "Brasileiros em [cidade/país]", "Vida no Exterior"              | Posts de desabafo ou celebração têm alta emoção                  |
| **TikTok**          | #storytime #brasileironoexterior #mudançadevida                         | Vídeos virais podem ser adaptados com permissão                  |
| **Substack/Medium** | Buscar "brasileiro imigração", "vida fora do Brasil"                    | Artigos pessoais são ouro — já têm estrutura narrativa           |
| **YouTube**         | Canais de vlogs de brasileiros no exterior                              | Comentários frequentemente têm histórias pessoais                |

### 2.2 Critérios de Seleção (Checklist)

A história deve ter:

- [ ] **Conflito claro** — O que deu errado? O que foi difícil?
- [ ] **Arco de transformação** — A pessoa mudou? Aprendeu algo?
- [ ] **Emoção palpável** — Dá para sentir o momento? Saudade, medo, alegria?
- [ ] **Especificidade** — Detalhes concretos (cidade, data, situação), não generalizações
- [ ] **Relevância para a comunidade** — Outros brazucas vão se identificar?
- [ ] **Resolução** — Tem um final? Não precisa ser perfeito, mas precisa ter encerramento
- [ ] **Tamanho adequado** — Dá para contar em 5-10 minutos? (750-1500 palavras)

### 2.3 Como Anonimizar

| Dado Original   | Anonimizado                                                 |
| --------------- | ----------------------------------------------------------- |
| Nome real       | Nome fictício brasileiro (ex: "Mariana", "Pedro")           |
| Cidade exata    | Região genérica (ex: "uma cidade no interior de São Paulo") |
| Nome da empresa | Tipo de empresa (ex: "uma startup de tecnologia")           |
| Datas precisas  | "Em 2019", "há cinco anos"                                  |
| Fotos           | Nunca usar sem autorização escrita                          |

> ⚠️ **Regra de ouro:** Sempre pedir permissão por DM/email antes de usar qualquer história. Oferecer anonimato completo.

## 3. Framework de Roteirização

### 3.1 Estrutura do Episódio (5-10 minutos)

```
TEMPO    ELEMENTO                    PALAVRAS
─────────────────────────────────────────────────
0:00     ABERTURA OFICIAL            — (fixo, 17s)
0:17     HOOK / GANCHO               30-50 palavras
0:45     INTRODUÇÃO DO PERSONAGEM    100-150 palavras
2:00     CONFLITO / DESAFIO          200-300 palavras
4:00     CLIMAX / VIRADA             150-200 palavras
5:30     RESOLUÇÃO / LIÇÃO           100-150 palavras
6:30     REFLEXÃO / MENSAGEM         50-80 palavras
7:00     FECHAMENTO OFICIAL          — (fixo, 15s)
─────────────────────────────────────────────────
TOTAL:   ~7-8 minutos de narração    ~750-1100 palavras
```

> 💡 **Dica:** Para histórias mais curtas (5 min), comprimir o conflito. Para histórias mais longas (10 min), expandir a introdução e o clímax.

### 3.2 O Hook (Gancho Inicial)

O hook é a frase mais importante do episódio. Se não prender nos primeiros 20 segundos, o ouvinte sai.

**Templates de Hook:**

1. **Impacto emocional:** _"Mariana tinha acabado de chegar em Londres com duas malas e zero libras na conta quando o dono do apartamento disse que ela tinha 24 horas para sair."_

2. **Pergunta provocativa:** _"Você já imaginou o que acontece quando você desiste de tudo — carreira, família, amigos — e descobre que o problema não era o Brasil, era você?"_

3. **Contraste chocante:** _"Ele era médico renomado em São Paulo. Seis meses depois de chegar em Toronto, estava lavando pratos em um restaurante chinês às 2 da manhã."_

4. **Estatística pessoal:** _"Três mil reais. Era tudo o que a família de Pedro tinha quando desembarcou em Lisboa. Em seis meses, virou zero."_

### 3.3 Marcações de Tags no Roteiro

O roteiro deve indicar onde usar tags expressivas e efeitos sonoros.

**Template de Roteiro:**

```markdown
# EP001 — [Título da História]

## Fonte: [Plataforma + link anônimo]

## Aprovado por: [nome fictício]

---

## HOOK (0:17-0:45)

[whispering] Mariana tinha acabado de chegar em Londres...
→ [efeito: stinger-sweep-up] (depois do hook)

## INTRODUÇÃO (0:45-2:00)

[narrating] Antes de 2019, Mariana morava em...
→ [bed: bed-neutral] (fundo sutil)

## CONFLITO (2:00-4:00)

[sighs] O primeiro mês foi o pior...
→ [efeito: impact-thud] (no momento da virada)
→ [bed: bed-suspense] (aumenta tensão)

## CLIMAX (4:00-5:30)

[excited] E aí, em um domingo de chuva...
→ [efeito: stinger-reverse-cymbal] (build para revelação)
→ [bed: bed-uplifting] (transformação)

## RESOLUÇÃO (5:30-6:30)

[smiling] Hoje, cinco anos depois...
→ [efeito: ui-success] (no momento da lição)
→ [bed: bed-hopeful] (encerramento)

## FECHAMENTO (6:30-7:00)

[warm] Obrigada por ficar comigo até aqui...
→ [efeito: stinger-sweep-down] (fade final)
```

### 3.4 Regras de Escrita para Narração

| ❌ Não fazer                         | ✅ Fazer                                                                                                  |
| ------------------------------------ | --------------------------------------------------------------------------------------------------------- |
| "Ela foi para Londres e ficou feliz" | "Quando o avião pousou em Heathrow, ela segurou a mão da filha e disse: 'Agora é só a gente'"             |
| "Foi muito difícil"                  | "Ela passou três noites seguidas acordada, olhando para o teto, perguntando se tinha feito a coisa certa" |

| Listar eventos cronologicamente      | Focar em 2-3 cenas-chave com detalhes sensoriais                                                          |
| Resumir emoções                      | Mostrar ações que revelem emoções                                                                         |

## 4. Pipeline de Produção de Áudio

### 4.1 Preparação do Roteiro

1. **Dividir o roteiro em segmentos** — Cada segmento tem UMA tag expressiva
2. **Limitar segmentos a 400 caracteres** — ElevenLabs funciona melhor com textos curtos
3. **Adicionar pausas artificiais** — `[pause]` ou `...` onde a Jessica deve respirar

### 4.2 Geração de Voz (ElevenLabs)

```bash
# Configuração fixa — NUNCA alterar
VOICE_ID=cgSgspJ2msm6clMCkdW9
MODEL=eleven_flash_v2_5
STABILITY=0.45
STYLE=0.80
SPEED=1.0
```

**Processo por segmento:**

```
Roteiro com tag → ElevenLabs API → MP3 raw
                     ↓
              [Verificar: tag foi
               interpretada ou falada?]
                     ↓
            Sim → Seguir
            Não → Cortar com silencedetect
                     ↓
              Aplicar pipeline ffmpeg
                     ↓
              Segmento processado
```

### 4.3 Pipeline FFmpeg por Segmento

```bash
# Step 1: Vari-speed + pitch drift
ffmpeg -i seg_raw.mp3 \
  -af "atempo=1.01,asetrate=43700,highpass=f=60,lowpass=f=10000" \
  -ar 44100 seg_step1.mp3

# Step 2: Room tone
ffmpeg -f lavfi -i "anoisesrc=color=pink:r=44100:duration=60" \
  -af "lowpass=f=4000,highpass=f=80,volume=0.025" \
  -ar 44100 roomtone.mp3

# Step 3: Mix + loudnorm
ffmpeg -i seg_step1.mp3 -i roomtone.mp3 \
  -filter_complex "
    [0:a]volume=1.0[voice];
    [1:a]volume=1.0[rt];
    [voice][rt]amix=inputs=2:duration=first[mixed];
    [mixed]loudnorm=I=-16:TP=-1.5:LRA=11[out]
  " -map "[out]" -ar 44100 -b:a 192k seg_final.mp3
```

### 4.4 Corte de Tag Falada

```bash
# Detectar silêncio inicial
ffmpeg -i seg_raw.mp3 -af silencedetect=noise=-30dB:d=0.1 -f null - 2>&1 | \
  grep -E "silence_start|silence_end"

# Cortar a partir do silence_end
ffmpeg -ss [silence_end] -i seg_raw.mp3 -c:a copy seg_limpo.mp3
```

### 4.5 Mix Final do Episódio

```
ABERTURA OFICIAL (17s)
    ↓
SEGMENTOS DE NARRAÇÃO (processados)
    ↓
EFEITOS SONOROS (nos pontos marcados)
    ↓
MÚSICA DE FUNDO (Mixkit Track 34, loopável se necessário)
    ↓
FECHAMENTO OFICIAL (15s)
    ↓
EPISÓDIO FINAL .mp3
```

**Ferramenta de mix:** Python manual (workaround ffmpeg 8.1.1 bug)

```python
# Pseudocódigo do mix
for sample in timeline:
    output = voice[sample]
    if music_active:
        output += music[sample] * 0.8
    if effect_active:
        output += effect[sample] * effect_volume
    output = clamp(output, -32768, 32767)
```

## 5. Uso da Identidade Sonora

### 5.1 Quando Usar Cada Efeito

#### Stingers / Transições

| Efeito                   | Momento                                  | Volume |
| ------------------------ | ---------------------------------------- | ------ |
| `stinger-sweep-up`       | Entrada de nova seção (intro → conflito) | -6dB   |
| `stinger-sweep-down`     | Saída de seção (resolução → reflexão)    | -6dB   |
| `stinger-whoosh`         | Corte rápido entre cenas                 | -6dB   |
| `stinger-reverse-cymbal` | Build antes de revelação/emocional       | -6dB   |
| `stinger-glitch`         | Transição para dados/fatos               | -8dB   |

#### Impacts / Hits

| Efeito            | Momento                  | Volume |
| ----------------- | ------------------------ | ------ |
| `impact-thud`     | Revelação de problema    | -8dB   |
| `impact-hit`      | Marcação de novo tópico  | -8dB   |
| `impact-boom`     | Clímax da história       | -6dB   |
| `impact-rim`      | ênfase rápida numa frase | -8dB   |
| `impact-metallic` | Descoberta/surpresa      | -8dB   |

#### Ambient Beds

| Efeito             | Momento                   | Volume |
| ------------------ | ------------------------- | ------ |
| `bed-neutral`      | Narração padrão           | -20dB  |
| `bed-warm`         | Momentos emocionais leves | -18dB  |
| `bed-suspense`     | Tensão, dificuldades      | -18dB  |
| `bed-uplifting`    | Superação, esperança      | -18dB  |
| `bed-dark-tension` | Momento de crise          | -16dB  |
| `bed-hopeful`      | Virada positiva           | -18dB  |

#### UI / CTA Sounds

| Efeito       | Momento                   | Volume |
| ------------ | ------------------------- | ------ |
| `ui-chime`   | Destaque de dica/conselho | -10dB  |
| `ui-bell`    | Intro de fato importante  | -10dB  |
| `ui-success` | Lição aprendida           | -8dB   |
| `ui-pop`     | CTA do Instagram          | -10dB  |

#### Identidade Exclusiva

| Efeito            | Momento                  | Volume |
| ----------------- | ------------------------ | ------ |
| `logo-sting`      | Reels/shorts do episódio | -4dB   |
| `logo-ident`      | Logo no início de vídeos | -4dB   |
| `signature-tone`  | Assinatura em transições | -6dB   |
| `build-countdown` | Contagem para revelação  | -6dB   |

### 5.2 Mapa Sonoro do Episódio (Exemplo)

```
0:00   [ABERTURA OFICIAL] — Música bed + voz
0:17   [stinger-sweep-up] → Entrada do hook
0:20   [bed-neutral] começa (fundo sutil)
0:45   [stinger-whoosh] → Corte para introdução
1:30   [impact-thud] → Momento do primeiro problema
2:00   [bed-suspense] substitui bed-neutral (tensão aumenta)
3:00   [stinger-reverse-cymbal] → Build para clímax
3:30   [impact-boom] → Clímax emocional
3:35   [bed-uplifting] → Transformação começa
5:00   [ui-success] → Lição aprendida
5:30   [bed-hopeful] → Encerramento emocional
6:00   [stinger-sweep-down] → Fade para fechamento
6:15   [FECHAMENTO OFICIAL] — CTA Instagram
6:30   Fim
```

## 6. Checklist de Produção

### Fase 1: Roteiro (Semana 1)

- [ ] Buscar 5+ histórias nas plataformas
- [ ] Selecionar 1 história (critérios de seleção)
- [ ] Pedir permissão por DM/email
- [ ] Anonimizar dados pessoais
- [ ] Escrever hook (3 opções, escolher a melhor)
- [ ] Escrever roteiro completo com marcações de tags
- [ ] Marcar pontos de efeitos sonoros
- [ ] Revisar culturalmente (brasileiro valida)
- [ ] Revisar brand voice (8+/10 na rubrica)
- [ ] Roteiro final aprovado

### Fase 2: Produção de Áudio (Semana 2 — Dias 1-2)

- [ ] Dividir roteiro em segmentos (1 tag por segmento)
- [ ] Gerar segmentos no ElevenLabs (Jessica, flash_v2_5)
- [ ] Verificar cada segmento: tag interpretada ou falada?
- [ ] Cortar tags faladas via silencedetect
- [ ] Aplicar pipeline ffmpeg em cada segmento
- [ ] Concatenar segmentos

### Fase 3: Mix e Efeitos (Semana 2 — Dias 3-4)

- [ ] Posicionar stingers nos pontos marcados
- [ ] Adicionar ambient beds nas seções apropriadas
- [ ] Adicionar impacts nos momentos de clímax
- [ ] Mixar com música de fundo (Mixkit Track 34)
- [ ] Adicionar abertura oficial no início
- [ ] Adicionar fechamento oficial no final
- [ ] Aplicar loudnorm final no mix completo
- [ ] Verificar níveis em 3 trechos (intro, corpo, fade)

### Fase 4: Revisão (Semana 2 — Dia 4)

- [ ] Ouvir episódio completo (1x sem interrupção)
- [ ] Ouvir episódio completo (1x com roteiro na mão)
- [ ] Verificar: a voz soa natural? (não robótica)
- [ ] Verificar: os efeitos não ofuscam a narração?
- [ ] Verificar: o clímax tem impacto emocional?
- [ ] Verificar: o fechamento tem CTA clara?
- [ ] Verificar: duração está entre 6-9 minutos?

### Fase 5: Entrega (Semana 2 — Dia 5)

- [ ] Exportar MP3 final (192kbps, 44.1kHz, mono)
- [ ] Nomear arquivo: `EP001_[tema-curto].mp3`
- [ ] Criar show notes / descrição do episódio
- [ ] Criar título otimizado para SEO
- [ ] Selecionar citação destacada para posts
- [ ] Produzir 3 shorts/reels dos melhores momentos
- [ ] Agendar publicação (quarta-feira, 19h BRT)

## 8. Cross-Posting e Reutilização

### 8.1 Estratégia de Conteúdo Multi-Plataforma

Um episódio gera **10+ peças de conteúdo:**

| Peça                 | Formato             | Plataforma                       | Quando      |
| -------------------- | ------------------- | -------------------------------- | ----------- |
| Episódio completo    | MP3 192kbps         | Spotify, Apple Podcasts, YouTube | Quarta, 19h |
| Short vertical (60s) | Reels/TikTok/Shorts | Instagram, TikTok, YouTube       | Quinta, 12h |
| Quote card           | PNG 1080x1080       | Instagram feed                   | Quinta, 19h |
| Thread Twitter/X     | 5-10 tweets         | X/Twitter                        | Sexta, 10h  |
| Carrossel            | 3-5 slides          | Instagram, LinkedIn              | Sábado, 12h |
| Audiogram (waveform) | Vídeo 30-60s        | Instagram Stories                | Quarta, 21h |
| Newsletter           | Texto + embed       | Email (Listmonk)                 | Quinta, 9h  |
| Blog post            | 800-1200 palavras   | Blog Muuday                      | Sexta, 12h  |
| LinkedIn post        | Texto longo         | LinkedIn                         | Segunda, 9h |

### 8.2 Shorts/Reels — Estrutura (60 segundos)

```
0-3s   [logo-ident] + Título do episódio na tela
3-10s  [Hook do episódio] — a frase mais forte
10-20s [Melhor cena emocional]
20-30s [Clímax — a virada]
30-45s [Resolução — o aprendizado]
45-55s [CTA] "Ouça a história completa no podcast Muuday"
55-60s [logo-sting] + @usemuuday
```

### 8.3 Audiogram (Waveform Video)

```bash
# Gerar audiogram com ffmpeg
ffmpeg -i episodio.mp3 -i thumbnail.png \
  -filter_complex "
    [0:a]showwaves=s=1080x400:mode=cline:colors=#9FE870[wave];
    [1:v]scale=1080:680[thumb];
    [thumb][wave]overlay=0:680[out]
  " -map "[out]" -map 0:a -shortest audiogram.mp4
```

Posso garantir:
✓ Anonimato completo (nome fictício, cidade genérica)

✓ Você pode pedir para não publicar a qualquer momento

O episódio terá entre 5-10 minutos e será narrado por uma voz
sintética (IA). Não usamos sua voz real.

Você topa conversar mais sobre isso?

| Nível           | O que fazer                             |
| --------------- | --------------------------------------- |

| **Profissão**   | Generalizar se muito específica         |
| **Empresa**     | Nunca nomear empresa real               |
| **Datas**       | Arredondar ("15 de março" → "em março") |
| **Fotos**       | Nunca usar sem autorização escrita      |

Adicionar nos show notes:
