# Studio

> Post-production. Where generated content becomes publishable.

## Podcast Studio

### `script/`
- Topic selector (from content calendar)
- Script writer (Claude 3.7)
- Script editor (human approval workflow)

### `voice/`
- ElevenLabs voice synthesis
- Voice clone (founder's voice or brand voice)
- Multi-speaker support

### `mixer/`
- Intro/outro music
- Background music
- Sound effects
- Audio leveling

### `distributor/`
- Spotify for Podcasters upload
- Apple Podcasts Connect
- RSS feed generation
- Podcast thumbnail generation

## Video Studio

### `editor/`
- Auto-cut based on script
- Subtitle generation (OpenAI Whisper)
- Music overlay
- Transitions and effects

### `renderer/`
- Render final video
- Multiple formats (9:16, 1:1, 16:9)
- Quality settings
- Export to publisher
