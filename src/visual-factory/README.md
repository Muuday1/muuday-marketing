# Visual Factory

> Where raw AI generation happens. Backgrounds, B-roll, avatars, assets.

## Modules

### `image-gen/`
- FLUX 2 via fal.ai (primary)
- Ideogram 3 (typography-heavy)
- Recraft V3 (vector, logos)
- Stable Diffusion 3.5 (local, free)

### `video-gen/`
- Pika (Reels, TikTok — fast social clips)
- Kling 3.0 (B-roll, cinematic scenes)
- Runway Gen-4.5 (ad creatives, controlled motion)

### `avatar/`
- HeyGen / Synthesia (presenter videos)
- ElevenLabs voice clone
- Lip-sync integration

### `asset-library/`
- Store all generated assets
- Tag and categorize
- Reuse assets across campaigns
- Auto-archive old assets

## Rules

1. **Never generate text in images** — that's Canvas's job
2. **Always enhance prompt with Brand DNA** — colors, style, mood
3. **Always save to asset library** — reuse is cheaper than regenerate
4. **Always track cost** — every generation is tracked
