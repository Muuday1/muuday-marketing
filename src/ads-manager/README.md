# Ads Manager

> Paid acquisition engine. Turn winning organic content into scalable ad campaigns.

## Modules

### `meta/`
- Campaign creation (awareness, traffic, leads, engagement)
- Ad set management (audiences, budgets, schedules)
- Creative management (upload, test, rotate)
- Pixel + Conversions API tracking

### `linkedin-ads/`
- Sponsored content campaigns
- Text ad campaigns
- Lead gen forms
- Retargeting audiences

### `creative-remixer/`
- Take winning organic post
- Remix for ad format (add CTA, adjust copy)
- A/B test variants
- Auto-pause underperformers

### `optimizer/`
- Daily budget reallocation
- Auto-pause campaigns with ROAS < 1.5x
- Scale winners (ROAS > 3x)
- Alert on anomalies

### `reports/`
- Daily spend report
- Creative performance report
- Audience insights
- Competitor ad analysis

## Budget Rules

| Funnel Stage | Budget % | Objective |
|--------------|----------|-----------|
| Awareness | 30% | Reach, video views |
| Consideration | 40% | Traffic, engagement |
| Conversion | 25% | Leads, signups |
| Retention | 5% | Engagement, community |
